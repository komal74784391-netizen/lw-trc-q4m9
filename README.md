# TR-4 Thermal Ramp Controller - design package

Released design package for the TR-4 controller, board revision TR-4.2.

## Contents
- `hardware/tr4-main.kicad_sch` - schematic, Rev 4.2
- `hardware/tr4-bom.csv` - production bill of materials
- `firmware/src/ramp.c` - closed-loop ramp engine
- `docs/thermal-compensation.md` - thermistor linearisation notes

## Status
The Rev 4.2 files are the released set. The controller ships with firmware 1.4.2.
